## ⚙️ Getting Started

Follow these steps to explore and execute the assignments locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Yash-0330/GEN-AI-ASSIGNMENT.git
```

### 2. Navigate to the Project Directory

```bash
cd GEN-AI-ASSIGNMENT
```

### 3. Create a Virtual Environment (Recommended)

```bash
python -m venv venv
```

Activate it on Windows:

```powershell
venv\Scripts\activate
```

### 4. Install Dependencies

Install the required libraries for the specific assignment.

For example:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

For the AI Greeting Application:

```bash
cd "10-Deployment Strategies_assignment/ai_greeting_app"
pip install -r requirements.txt
```

### 5. Run Jupyter Notebook

```bash
pip install notebook
jupyter notebook
```

Open the required `.ipynb` file and execute the cells sequentially.

### 6. Run the Streamlit Application

```bash
streamlit run app.py
```

**Note:** Some Generative AI assignments require a valid Google Gemini API key. Configure API credentials securely using Streamlit secrets or environment variables. Never upload API keys to GitHub.

## 🔐 Security & Best Practices

- API keys and passwords should never be committed to GitHub.
- Use `.gitignore` to exclude sensitive configuration files.
- Store API credentials using environment variables or secure secrets management.
- Use virtual environments to manage project dependencies.
- Keep datasets and project documentation organized.
